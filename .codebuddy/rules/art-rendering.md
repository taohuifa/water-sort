# 美术素材与渲染方式规范

适用范围：本项目所有视觉/美术元素（瓶子、液体、饮品、UI 装饰等）。

## 核心原则（2026-10-27 用户定稿）

**只走素材位图拼接，禁止 API 程序化绘图充当美术元素。**

| 项 | 规定 |
|----|------|
| 素材来源 | ① 用户参考图直接抠图（首选，最忠实）；② 参考图模板离线重上色（形状复用换色）；③ AI 生成（imagegen MCP，须逐张验收） |
| 运行时渲染 | 只允许 `drawImage` 切片/拼接/拉伸（三段式：顶盖固定 + 主体拉伸 + 底盖固定） |
| 禁止 | `fillRect` / `ellipse` / `arc` / `path` 等程序化绘制充当液体、器皿、装饰等美术元素；半透明色罩叠加（如椰子白麦色罩）同禁 |
| 例外 | 纯文本（「?」、数字、按钮文字）允许 `fillText`；非美术的交互提示（选中框、角标）暂允许矢量，逐步素材化 |
| 分隔线等细节 | 烘焙进素材（如白色分隔线做成 1×N 白色 PNG 拉伸），不用 fillRect 画 |

## 素材管线约定

- 抠图脚本：`tools/extract-*.ps1`（背景色键/描边定位，米色 bg 252,243,227）
- 重上色脚本：`tools/recolor-*.ps1`（亮度保持映射：暗部乘 shade、亮部向白渐近，
  模板基准色 → 目标色，保留高光/阴影/盘面结构）
- 素材验收：逐张肉眼 + 用前检查（透明差分/色键管线概率性损坏）
- 任何新美术需求，先问：参考图里有没有？有就抠，没有才离线换色/AI 生成

## 液体素材标准管线（2026-10-27 v4 定稿）

色键抠图会把背景色混进边缘抗锯齿像素（米色 bg → 渲染白框），液体改走 AI 生成 + 白模滤色：

1. **AI 生成干净 PNG**：imagegen 图生图（输入参考图，transparent 直出）
2. **清边**：`tools/process-liquid-ai.ps1`——alpha 阈值切光晕 → 腐蚀 → 羽化 →
   白色去污染（c = a·F+(1-a)·255 反解）→ 裁剪 → 128 宽主图
3. **白模**：`liquid-tpl-white.png`（不带颜色光影图，p = 127.5×L/Lbody）
4. **滤色**：out = min(255, p×2×rgb/255) → 9 色（与 drinkTint 白模方案同构）
5. 生成物带光晕/白边是常态，清边步骤不可省；重生成后需按新主图重标切片比例
