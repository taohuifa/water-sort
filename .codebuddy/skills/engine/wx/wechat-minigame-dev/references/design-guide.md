## 平台定位与特征

微信小游戏是微信小程序的特别类目，核心特征：

- **即点即玩**：无需下载、安装与卸载
- **社交驱动**：与微信关系链深度结合，好友 PK / 围观是核心分发方式
- **轻量为主、重度亦可**：大部分用户期望轻松休闲的体验，但平台也支持通过分包等能力承载重度游戏
- **无集中流量入口**：小游戏在微信中没有集中的应用商店式分发，传播主要依赖社交裂变，因此**设计可传播的元素**是获取用户的关键

### 用户发现路径

| 入口 | 说明 |
|------|------|
| 微信主界面下拉 | 显示最近使用的小程序 / 最近玩过的小游戏 |
| 搜一搜 | 搜索游戏名称直接进入 |
| 发现 → 游戏 | 官方游戏入口页 |
| 好友分享 | 通过聊天会话中的分享卡片进入（最主要的拉新方式） |

## 游戏体验设计

### 2.1 玩法设计

好的玩法需要具备四要素：

1. **明确的获胜条件** — 玩家知道怎样算"赢"
2. **清晰的规则** — 交互逻辑直觉可理解
3. **实时的反馈系统** — 每个操作有即时正向/负向反馈
4. **自愿参与** — 玩家出于内驱力而非强制

创新方向：可以设计全新的玩法类型，也可以在传统玩法基础上革新（如加入社交竞技元素）。

### 2.2 叙事体验

围绕四个要素打造沉浸感：

- **独特的故事背景设定** — 区别于其他同类游戏
- **角色个性刻画与代入感** — 让玩家产生情感连接
- **情节递进与支线设置** — 维持长线兴趣
- **留白空间** — 给玩家想象和讨论的余地

### 2.3 美术体验

需要关注五个维度：UI 界面设计、色彩运用、原画风格、氛围营造、动效设计。目标是突破既有视觉风格，形成辨识度。

### 2.4 听觉体验

音效/音乐来源建议多样化：原创配乐、古典音乐改编、打击乐、乐器合成、自然环境声采集。好的音效能显著提升沉浸感和品质感。

### 2.5 新手引导

| 原则 | 说明 |
|------|------|
| 渐进式教程 | 分步骤教学，不要一次性灌输所有规则 |
| 演示引导 | 边玩边学，避免大量文本堆积 |
| 明确入口 | 提供清晰的学习路径，玩家能随时回看 |
| 适度规则告知 | 只说必要的，保留探索和发现的乐趣 |
| 复活/容错机制 | 给新手充分的准备时间和犯错空间 |

### 2.6 界面布局

#### 设计基准分辨率

- **基准尺寸：750 × 1334 px**（对应 4.7 英寸屏幕，iPhone 6/7/8）
- 其他设备按比例缩放适配
- 异形屏（刘海屏）需单独处理安全区域

#### 拇指热区原则

基于单手持握习惯，将界面划分为不同可达性区域：

- **易达区（底部 1/3）**：放置高频操作按钮（攻击、跳跃等核心玩法操作）
- **可达区（中部）**：放置次要交互元素
- **难达区（顶部）**：放置低频信息展示（分数、状态栏等只读信息）

#### 布局建议

- 核心操作控件要足够大，间距合理，避免误触
- 考虑横屏/竖屏不同场景下的布局差异
- 重要信息避开刘海、圆角等系统遮挡区域
- 按钮热区建议不小于 80 × 80 rpx

## 传播性设计

小游戏在微信内没有集中流量入口，传播设计是获取用户的核心手段。

### 3.1 多人玩法与动态消息

- 设计好友间对抗 / 合作 / 组队功能，充分利用微信社交关系
- 接入**动态结构化消息能力**：分享到群的消息可在人数、状态变化时自动更新内容，增加消息吸引力并减少挫败感（如"等待 2/4 人加入"变为"3/4 人已加入"）

### 3.2 观战功能

- 提供分享到会话的观战/战局回顾邀请卡片
- 转化未能及时参与的好友，扩展活跃用户来源

### 3.3 排行榜设计

| 类型 | 要点 |
|------|------|
| 好友排行 | 展示微信好友间的排名，调动熟人竞争心理 |
| 世界排行 | 给高水平玩家提供更大的舞台 |
| 群排行 | 在微信群内生成排行，有效调动群内游戏话题 |

设计要点：
- 在排行变化时**主动通知玩家**（如"你超越了好友 XXX"）
- 游戏过程中超越好友时**即时标识**，形成个性化里程碑记忆
- 设置排行榜**更新周期**（每日/每周/每赛季清零），制造周期性竞争动力

### 3.4 分享节点设计

#### 核心原则

> 分享操作应该是用户的真实意愿表达，不能通过利诱、强制等方式进行。

#### 具体规范

| 规范 | 要求 |
|------|------|
| 频次限制 | **每一次游戏过程中，分享节点不宜超过 1 个** |
| 自愿原则 | 禁止强制分享（如"分享后才能继续"） |
| 奖励平衡 | 分享奖励不应损害游戏的平衡性，否则会加速玩家流失 |
| 数量精简 | 宜少宜精不宜多，避免"选择的悖论" |

#### 高转化分享题材

1. **知识分享** — 有价值的信息、攻略、技巧
2. **炫耀性分享** — 高分、稀有成就、排名
3. **个人创作** — 用户在游戏中的创造内容
4. **反差冲突** — 出人意料的结果，引发好奇
5. **物品收集** — 展示收集进度，引发讨论

### 3.5 分享卡片设计

#### 强制要求

- **内容一致性**：点击分享卡片进入游戏后的体验**必须与卡片内容呼应**，前后不一致会导致用户秒退
- **禁止诱导点击**：不要借热点话题或擦边球等不相关内容诱导用户点击

#### 设计建议

- 为不同场景设计**差异化卡片**（结算分享 vs 邀请组队 vs 求助）
- 融入**用户个性化内容**（用户头像、昵称、成绩）
- 文案要**口语化、情感化**，像朋友说话而非广告

### 3.6 互推跳转设计

- 固定展示的推荐游戏**不超过 5 个**，可放在侧边或下方
- 超过 5 个必须使用**抽屉式浮层**等收纳交互
- **不得妨碍或遮蔽**游戏界面主要元素
- **不得占用大篇幅界面**吸引或诱导玩家点击
- 关闭按钮必须清晰可见且及时出现

## 留存设计

### 4.1 周期性目标

设置多层次时间维度的目标体系：

| 周期 | 示例 |
|------|------|
| 单次游玩 | 本局最高分、通关奖励 |
| 每日 | 每日任务、签到奖励、每日挑战 |
| 每周 | 周排行榜重置、周常任务 |
| 长期 | 赛季目标、累计成就、等级上限 |

关键设计：排行榜设置**清零周期**，让玩家产生周期性竞争动力。每次超越/登顶事件可重新引发社交讨论。

### 4.2 收集系统

- 在游戏过程中设置**图鉴 / 收集系统**
- 在主界面体现**收集进度**，让玩家始终看到"还差什么"
- 为玩家提供长期且有趣的游戏目标

### 4.3 特殊成就与彩蛋

- 利用成就系统、道具系统设置**主线之外的趣味目标**
- 引导完成特殊挑战或发现隐藏彩蛋
- 提供额外奖励作为激励

### 4.4 社区与用户关系

- 配置**游戏圈**（微信官方社区功能）收集玩家反馈
- 配置**游戏客服**提供沟通渠道
- 根据用户建议调整系统设计，提升满意度和持续投入意愿

## 商业变现设计

### 5.1 虚拟支付

**前提**：需先在微信公众平台开通虚拟支付能力，再接入商业系统。

#### 付费设计类型

| 类型 | 说明 |
|------|------|
| 英雄 / 皮肤解锁 | 通过付费解锁角色和外观 |
| 游戏币系统 | 提供虚拟货币购买能力（不同面额、首充优惠等） |
| 功能道具 | 游戏内消耗品（加速卡、复活币等） |
| 周期性增值服务 | 月卡、赛季通行证、VIP 订阅 |
| 抽卡 / 扭蛋系统 | 概率性获得稀有内容 |

#### 设计原则

- 商业系统应**提升核心玩家体验**，而非破坏游戏平衡
- 付费内容要让玩家感到"物有所值"
- 免费玩家也应有完整的游戏体验

### 5.2 Banner 广告

- 广告是大多数小游戏商业化变现的重要途径
- 需严格遵守微信广告规范，避免违规处罚
- 注意：Banner 广告（`createBannerAd`）已于基础库 3.5.5 废弃，推荐使用其他广告形式

### 5.3 激励视频广告

激励视频是目前**转化率最高、用户体验最好**的广告形式。推荐的接入场景：

| 场景 | 说明 |
|------|------|
| 奖励倍增 | 游戏结束后观看视频获得 2x/3x 倍数奖励 |
| 额外机会 | 观看视频获得复活 / 重新挑战的机会 |
| 游戏帮助 | 遇到困难时观看广告获得提示或道具 |
| 虚拟货币替代 | 不愿付费的用户可通过看广告获得游戏币 |

#### 设计要点

- 激励视频应在**自然的游戏节点**出现（如死亡、结算、商店）
- 不要强迫用户观看，始终提供"跳过"选项
- 广告奖励应该有吸引力但不破坏付费体系

## 设计自查清单

### 体验设计
- [ ] 核心玩法有明确的获胜条件和反馈系统
- [ ] 新手引导采用渐进式教学，避免文本堆积
- [ ] 界面布局以 750×1334 为基准，适配异形屏安全区域
- [ ] 高频操作按钮在拇指易达区（屏幕底部 1/3）

### 传播设计
- [ ] 设计了至少一种社交互动玩法（对战/合作/排行）
- [ ] 分享节点符合"每次游戏过程不超过 1 个"的限制
- [ ] 分享卡片内容与实际游戏体验一致
- [ ] 互推跳转固定展示不超过 5 个，不遮蔽游戏界面
- [ ] 无强制分享、利诱分享行为

### 留存设计
- [ ] 有多层次周期目标（每日/每周/长期）
- [ ] 排行榜设置了清零周期
- [ ] 有收集/成就等长线目标系统

### 变现设计
- [ ] 虚拟支付已开通且商业系统不破坏游戏平衡
- [ ] 激励视频广告出现在自然游戏节点
- [ ] 免费玩家有完整游戏体验
