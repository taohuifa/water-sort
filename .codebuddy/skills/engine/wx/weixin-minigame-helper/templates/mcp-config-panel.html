🛠 可用工具

AI 连接 MCP 后可使用以下工具来控制小游戏预览：

run_game 启动小游戏预览，打开预览面板并加载游戏
reload_game 重新加载当前运行的游戏（热重载，无需重启服务）
stop_game 停止游戏，关闭预览面板和本地服务器
get_logs 获取游戏控制台日志，支持正则过滤
real_device_preview 编译并上传到微信平台，生成真机预览二维码（需提前配置 AppID 和上传密钥）
publish 通过 CI 将小游戏开发版上传到微信平台，需传入版本号和项目备注（需提前配置 AppID 和上传密钥）
❓ 常见问题

Q: 配置后 AI 工具找不到 MCP 工具？
A: 请确保 VSCode 已安装此插件并已启动。MCP Server 在插件激活时自动运行，AI 工具需要能找到 Node.js 并执行 server.js 文件。


Q: 多个工作区可以共享同一个 MCP 配置吗？
A: 是的，MCP Server 路径是插件安装路径下的固定位置，不同工作区可以使用相同的配置。


Q: 更新插件后需要重新配置吗？
A: 如果插件安装路径没变则无需重新配置。如果更新导致路径变化，可以点击「一键配置」重新生成。
